# Reproductive Strategies and Larval Traits in Deep-Sea Sponges (Poecilosclerida)

[Last updated 18 Nov 2026]

This repository contains the R scripts and reproducible workflow used for the analyses presented in the manuscript *“Reproductive strategies, maternal investment and larval traits in deep-sea sponges (Poecilosclerida)”*. The study investigates reproductive modes, gametogenesis, maternal investment, and larval morphology in deep-sea poecilosclerid sponges, using histological, transmission electron microscopy (TEM), and micro-computed tomography (microCT) approaches. The analyses also explore relationships between global Poecilosclerid larval size, depth, and latitude.

The repository includes the R Markdown file containing the code used for data processing, statistical analyses, and visualisation, together with the knitted PDF output documenting the analyses.
